# Loveworld TTU Church Website

A web app for Loveworld TTU (Takoradi Technical University) with:
- Public site (home, about, contact, service times)
- Member login
- Dashboard for pastors and cell leaders
- Member directory (name, phone, email, ID, hall, cell)
- Cell group management

## Tech
- HTML / CSS / JavaScript
- Firebase (Auth + Firestore)
- Firebase Hosting / Netlify
